# CANary AI Prototype - Quickstart Guide

This guide provides instructions to quickly set up and run the CANary AI prototype project, which simulates CAN bus data, analyzes it, and uses the Google Gemini API for generating diagnostic instructions.

## Prerequisites

Before you begin, ensure you have the following installed:

1.  **Python:** Version 3.12 or higher recommended.
2.  **pip:** Python package installer (usually comes with Python).
3.  **Google AI Studio API Key:** You need an API key to use the Gemini LLM. Get one from [Google AI Studio](https://aistudio.google.com/app/apikey).

## Setup Instructions

1.  **Get the Code:**
    Make sure you have the project code files organized in a directory structure like this:

    ```
    your_project_folder/
    ├── canary_ai/
    │   ├── can_emulator.py
    │   ├── decoder.py
    │   ├── analyzer.py
    │   ├── dashboard.py
    │   ├── main.py
    │   ├── templates/
    │   │   └── index.html
    │   └── requirements.txt
    ```

2.  **Navigate to Project Directory:**
    Open your terminal or command prompt and change to the directory containing the `canary_ai` folder. For example:

    ```bash
    cd path/to/your_project_folder/canary_ai
    ```

3.  **Install Dependencies:**
    Install the required Python libraries using `pip` and the `requirements.txt` file:

    ```bash
    pip install -r requirements.txt
    ```

4.  **Configure Google API Key:**
    You **must** set your Google API key as an environment variable named `GOOGLE_API_KEY`. **Do not hardcode your key in the Python files.**

    *   **Linux/macOS:**
        ```bash
        export GOOGLE_API_KEY='your_actual_google_api_key_here'
        ```
        *(Note: This sets the variable only for the current terminal session. Add it to your `.bashrc` or `.zshrc` for persistence.)*

    *   **Windows (Command Prompt):**
        ```cmd
        set GOOGLE_API_KEY=your_actual_google_api_key_here
        ```
        *(Note: This sets the variable only for the current command prompt session.)*

    *   **Windows (PowerShell):**
        ```powershell
        $env:GOOGLE_API_KEY = 'your_actual_google_api_key_here'
        ```
        *(Note: This sets the variable only for the current PowerShell session. Use System Properties for persistence.)*

    Replace `'your_actual_google_api_key_here'` with your actual API key.

## Running the Application

1.  **Start the Main Script:**
    With the environment variable set and dependencies installed, run the `main.py` script from within the `canary_ai` directory:

    ```bash
    python main.py
    ```

2.  **Observe Output:**
    You should see output in your terminal indicating:
    *   Google GenAI configuration status (success or warning about missing key).
    *   Emulator starting.
    *   Flask server starting (usually on `http://0.0.0.0:5000`).
    *   Log messages from the processor about analysis and potentially LLM calls.

## Accessing the Dashboard

1.  **Open your Web Browser:**
    Navigate to the following URL:

    ```
    http://127.0.0.1:5000
    ```
    or
    ```
    http://localhost:5000
    ```

2.  **View Dashboard:**
    You should see the CANary AI dashboard displaying:
    *   Live status (OK, WARNING, ERROR, CRITICAL).
    *   Live metrics (RPM, Speed, Temp, Fuel).
    *   Active DTCs (Diagnostic Trouble Codes).
    *   Recommended actions and instructions (generated by Gemini API if an issue is detected and the API key is valid).

    *Note: The dashboard uses Server-Sent Events (SSE) for live updates.*

## Stopping the Application

1.  **Go to the Terminal:** Return to the terminal window where `python main.py` is running.
2.  **Press `Ctrl+C`:** This will send a KeyboardInterrupt signal. The application is designed to catch this and attempt a graceful shutdown (stopping the emulator and threads).

## Notes

*   **LLM Usage:** The application calls the Google Gemini API (`gemini-1.5-flash` by default, configurable in `analyzer.py`) whenever an issue requiring diagnostic or repair instructions (`DIY_DIAGNOSTIC`, `DIY_REPAIR` action types) is detected. Ensure your API key is valid and has necessary permissions/billing enabled if required by Google.
*   **Simulation:** Remember this prototype uses a *simulated* CAN bus (`can_emulator.py`). It does not connect to a real car. The "self-healing" is also simulated by printing messages and interacting with the simulator's state.
*   **Troubleshooting:**
    *   If the LLM instructions show errors or fallback messages, double-check your `GOOGLE_API_KEY` environment variable and ensure you have internet connectivity.
    *   If you encounter module import errors, ensure you ran `pip install -r requirements.txt` successfully in the correct directory.
